# 基金对比

`fund compare` 命令支持多只基金的横向对比分析，包括业绩指标对比、滚动胜率对比、相关性分析和对比报告生成。

## 多基金横向对比

对比多只基金的总收益率、年化收益、波动率、最大回撤和夏普比率。

```bash
# 对比3只基金（默认1年周期）
fund compare funds 000001 000002 000003
```

## 分析周期选择

通过 `--period` 参数指定不同的分析周期。

```bash
# 近3个月对比
fund compare funds 000001 000002 --period 3m

# 近6个月对比
fund compare funds 000001 000002 --period 6m

# 近1年对比（默认）
fund compare funds 000001 000002 --period 1y

# 近3年对比
fund compare funds 000001 000002 --period 3y
```

支持的周期参数：

| 参数 | 时间跨度 |
|------|----------|
| `1m` | 近1个月 |
| `3m` | 近3个月 |
| `6m` | 近6个月 |
| `1y` | 近1年（默认） |
| `3y` | 近3年 |

## 对比维度说明

横向对比涵盖以下核心维度：

| 维度 | 说明 |
|------|------|
| 总收益率 | 分析区间内的累计收益 |
| 年化收益 | 折算为年化的收益率（CAGR） |
| 年化波动 | 收益率的标准差，衡量风险 |
| 最大回撤 | 区间内最大跌幅，衡量极端风险 |
| 夏普比率 | 单位风险的超额收益，综合评价 |

## 滚动胜率对比

计算滚动窗口下各基金战胜其他基金的频率。

```bash
# 60个交易日滚动窗口，对比2只基金
fund compare rolling-win 000001,000002 --window 60
```

```bash
# 指定分析周期
fund compare rolling-win 000001,000002,000003 --window 120 --period 2y
```

预期输出：


## 相关性分析

计算多只基金之间的收益率相关系数矩阵。

```bash
fund compare correlation 000001,000002,000003
```

预期输出：

```

┏━━━━━━━━┳━━━━━━━━┳━━━━━━━━┳━━━━━━━━┓

┡━━━━━━━━╇━━━━━━━━╇━━━━━━━━╇━━━━━━━━┩
```

相关性矩阵中，绿色表示高正相关（>0.5），红色表示负相关（<-0.3），无色表示中等相关。

## 对比报告生成

将对比结果导出为 Markdown 报告文件。

```bash
# 生成对比报告
fund compare report 000001,000002,000003 --period 1y
```

```bash
# 指定输出路径
fund compare report 000001,000002 --output my_comparison.md
```

预期输出：

```
对比报告已生成: comparison_report.md
```

生成的报告包含各基金的收益率、波动率、夏普比率和最大回撤的对比表格。
