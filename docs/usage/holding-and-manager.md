# 持仓与经理分析

本模块涵盖基金持仓分析（`fund holding`）和基金经理分析（`fund manager`）两大功能，帮助你深入了解基金的持仓结构和基金经理的管理能力。

## 持仓查询

查看基金的前 N 大重仓股。

```bash
# 查看前十大持仓（默认）
fund holding query 000001
```

```bash
# 查看前五大持仓
fund holding query 000001 --top-n 5
```

## 持仓集中度分析

通过 HHI 指数评估基金持仓的集中度。

```bash
fund holding concentration 000001
```

预期输出：

```
000001 持仓集中度：
  HHI指数: 0.0250
  集中度等级: 中等集中
```

HHI 指数说明：

| HHI 范围 | 集中度等级 |
|-----------|-----------|
| < 0.01 | 低集中度 |
| 0.01 - 0.05 | 中等集中 |
| > 0.05 | 高集中度 |
