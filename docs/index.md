# Fund CLI 文档

## 安装

```bash
pip install fund-cli
```

## 快速开始

```bash
fund --help
fund config
fund filter basic --type 股票型
fund analyze info 000001
fund analyze metrics 000001
fund compare funds 000001 000002
```
